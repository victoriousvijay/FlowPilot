# Roadmap

- Natural language generation
- Visual workflow
- 5 integrations
- Save/test/activate
- Execution history

## V1.5 — AI workflow copilot
- "Add this step"
- "Change this condition"

- "Fix this workflow"
- Natural-language edits to existing workflows

## V2 — Automation platform
- Scheduler
- retries
- branching
- delays
- approvals
- richer credential management
- templates
- reusable actions

## V3 — Business platform
- teams
- workspaces
- roles
- billing
- usage limits
- audit logs
- marketplace
- analytics

## Long-term differentiator
Do not compete only on number of integrations. Compete on how quickly a user can go from:
**idea → working automation.**
