# Product Design Direction

## Brand
The product should feel like a premium AI operating system for automation.

Primary concept:
**Describe it. We automate it.**

## Experience
The first screen should be centered around one action:
"What do you want to automate?"

Example prompt:
"Whenever a new lead submits my website form, add them to Sheets and notify Slack."

Primary CTA:
"Generate automation"

## Visual language
- Modern
- Minimal
- Premium
- Dark-first is acceptable
- Strong typography
- Generous spacing
- Subtle motion
- Clear hierarchy
- Avoid excessive gradients, glowing cards, and decorative noise

## Workflow canvas
The canvas should make the generated automation understandable at a glance.

Nodes should show:
- integration icon
- action
- short description
- status
- configuration state

The editor is secondary to natural-language creation.

## States
Design explicit states for:
- empty
- generating
- generated
- needs connection
- testing
- successful
- failed
- active
- paused
